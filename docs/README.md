# Base.Auth documentation

| Guide | Use it to |
|---|---|
| [Machine-to-machine authentication](m2m.md) | Integrate the .NET client and API, provision keys, configure persistence, and run the reference applications. |
| [Local user authentication](local-users.md) | Provision local accounts and public clients, enable browser sign-in, and integrate the user token flow. |
| [Testing](testing.md) | Run unit, integration, and Windows compatibility tests. |
| [Target architecture](architecture/target-architecture.md) | Understand the design for user sign-in, federation, authorization, and deployment. |
| [Extensibility design](architecture/extensibility.md) | Understand how applications can compose or replace components. |

The M2M and local user guides document the available functionality. The architecture guides
describe the target design for additional providers and product authorization.
